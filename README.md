# College Major Salary Analysis with Pandas

A comprehensive data exploration project analyzing salary data across different college majors using Python's Pandas library.

## Dataset
- **File**: `salaries_by_college_major.csv`
- **Records**: 50 college majors
- **Columns**: 6 data fields including starting salary, mid-career salary, percentile ranges, and major groupings

## Analysis Features
- Data cleaning and exploration techniques
- Salary comparisons across majors
- Career progression analysis (starting vs mid-career)
- Grouping by field types (STEM, Business, HASS)
- Missing data identification and handling

## Usage
Open `Data_Exploration_Pandas_College_Major.ipynb` in Jupyter Notebook or Google Colab to explore the analysis.

## Requirements
- Python 3.x
- Pandas
- Jupyter Notebook (optional)
